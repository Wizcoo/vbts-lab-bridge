# H20 平面 VBTS · 种子 17 力阶实验

本实验用球头在同一位置加载，同时记录六维力计和模型估计的法向力。模型从位移场的 31 个描述量估计一个 Fz。它由多点位数据重新训练，采用 32 个隐单元。显示以按压为正，记录同时保留软件坐标下的带符号 Fz。适用型号为 **HSMVBTS_G01_H20_000011，H20 平面，640×480**。当前状态为实验候选。

## 准备与自检

在此 PR 的仓库根目录运行。设备端需要 Windows x64、64 位 Python（建议 3.12）、NumPy、Python OpenCV，以及现有 SDK 的 OpenCV 4.4 和 HPS 力计驱动。可沿用已能运行仓库采集器的 Python 环境；新环境可安装仓库的 `device/requirements.txt`。脚本自检只处理生成的纹理图，不连接设备。

```powershell
.\device\seed17\run_lab.ps1 -SdkRoot 'D:\HSMVBTS\sdk_dist_identity'
```

路径替换为实际 SDK 目录，可通过 `-Python 'D:\vbts-env\Scripts\python.exe'` 指定 Python。自检核对权重、跟踪模块和 SDK DLL 的 SHA-256，并检查生成图的预测与重复性。遇到 DLL 错误先核对位数、Windows x64 VC++/OpenMP 运行库及 `manifest.json` 中的 DLL 哈希。

## 当天下午的采集

确认当前设备、胶体、球头、安装法向和安全载荷。填写胶体或设备标识及点位。将 `-Camera 0` 替换为实际相机索引；力计支持指定现用 `-Port 'COM3'`，省略时使用设备 SDK 默认发现。在现场确认设备可用后运行：

```powershell
.\device\seed17\run_lab.ps1 -SdkRoot 'D:\HSMVBTS\sdk_dist_identity' -Capture -Camera 0 -Specimen '000011-gel-A' -Position 'center'
```

1. 球头与胶体完全脱离、胶体恢复后，按 **T** 做一次力计置零并建立无载参考。看到参考就绪后按 **R** 开始记录。先按 **0** 标记无载平台。读取参考和置零的故障会写入日志；重新置零仅在确认无载时进行。
2. 建议从同一中心点做 **0 → 1 → 3 → 5 → 3 → 1 → 0 N**，只使用型号和球头获准的载荷。每次改变力之前按 **B** 结束当前平台。看六维力计到达目标附近并保持，再按 **1 / 3 / 5 / 0** 标记平台起点。每档先试约 5 秒作为诊断起点，实际参考波动照常保留。不要用模型预测决定达到目标。首轮优先 1 N；极弱力和大载荷可另开实验。
3. 按 **Esc** 正常结束并自动生成报告。建议同一位置完全卸载后独立重做 3 轮，然后换一个边缘位置建立新 session。每次用同一球头并记位置。手压波动时，仍然可以检查变力跟踪；评价“恒力漂移”前先核查实际平台是否够稳。

窗口显示最近已记录配对的帧号、年龄、模型与参考读数。B 表示过渡；标记只用于分段，标签始终使用当帧实测。若实时显示陈旧或配对失败，结合帧号和 `pair_status` 判断。程序不控制位移台或夹爪。

## 怎么判结果

原始资料在 `local_data/seed17/session_...`，报告在旁边的 `*_seed17_report_...`。报告画两条曲线并按每段列出参考实际均值和峰峰值、模型均值与峰峰值、Bias、MAE、P95、最大误差和首末 20% 时间窗口平均误差差。失效的样本保留在 `frames.csv`，无效参考不参加误差统计。参考全流见 `force_raw.csv`；帧与参考的配对及原图见 `capture_sync.csv`。图像与力计用主机采样时刻配对，动态物理延迟仍待独立同步实验。运行和原始数据保留在设备端。

若实际参考在 1.03 N 一带稳定，预测在 0.55 N 一带稳定，阶梯形状正确但该档低估约 0.48 N。若参考和预测一起随手压变化，并且差值小，则这段提供的是变力跟踪证据。讨论中的 ±0.1 N 请分别检查平台均值偏差、逐帧 P95 和重复加载差异，再决定采用哪个验收口径。一场中心点试验支持对应设备、位置、物体和力段；正式判断需再看异日、边缘及不同胶体。

可重建报告，原 session 保持只读：

```powershell
python device\seed17\lab.py report 'D:\path\to\session_...'
```

单对原图可用 `lab.py predict --opencv-dll ... --reference before_contact.png --image press.png`。模型以固定无载参考取蓝通道，DIS 每帧从零流场开始，逐帧重新计算，无时域冻结或显示滤波。参考光学图更新和力计去皮都写入事件记录。生产六维模型独立于本目录；回退只需退出程序并使用原设备软件。

## 软件验证

独立分析端在 7 个实际点位、203 个历史平台上使用打包程序重算 609 次，对照先前冻结的 SDK 预测最大差小于 0.000001 N。所用原图保留在分析端。自检的生成纹理用于验证安装与实现一致性，不代表设备精度。新增的 Windows x64 原生模块仅提供固定参考、B 通道位移场接口，编译入口见 `native/bridge.cpp`。构建需要内部 SDK 的相应 tracker 和匹配的 OpenCV 4.4 开发包；设备复现可直接使用随附模块。候选权重单独保存于 `seed17.json`，仅提供 Fz。
