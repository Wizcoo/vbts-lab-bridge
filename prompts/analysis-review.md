# 给本机分析 agent 的审核任务

读取 AGENTS.md、合同和实验室 PR；不要要求设备端复制训练 dataset。

核对 checkout/模型/配套配置/数据包身份和哈希；检查原始双流是否存在、完整保存、时间基准是否可信、单位/坐标/力矩原点/标定是否闭合。实际运行完整性工具并保存日志，复核质量报告，不能只信 README。

优先分析同一段记录：原始帧 -> 位移场 -> 编码 -> 实际网络输入 -> ONNX 原始输出 -> 显示值/六维力标签。先定位首次差异，不直接重训或搜索测试最优延迟/偏置。

本地 dataset 保持只读；记录暴露边界与参考/会话隔离。相同 session 回放候选时分别使用冻结的 ONNX+配置，不覆盖现役资产。

报告六轴 MAE/RMSE/Bias/P95/Max，激励不足 Pearson=N/A；没有同步/标定/动作依据时明确哪些物理结论不能成立。保留全部异常和失败。

提交审核：ACCEPT / CHANGES_REQUESTED / REJECT，逐项附文件/日志证据、优先级、修复办法及受影响重测。给下一轮一个有限任务。代码合并不等于模型发布；硬件执行和替换需要人员明确授权。
