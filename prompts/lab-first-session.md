# 给实验室 PC agent 的首轮任务

请读 AGENTS.md 和 docs/session-contract.md，在独立分支完成首轮诊断数据交接。此 PC 不需要本机训练 dataset。

先盘点：实际工作目录/提交、设备连接、当前运行入口、已加载 ONNX/TXT/DLL 的路径和哈希、原始图像/六维力时间戳来源、现有 session 可恢复字段。不要默认设备已连接。

若未连接 VBTS 或六维力计：仅整理旧 session、开发适配和离线检查，报告 BLOCKED；不得用模拟数据冒充新实测。不要自行操作机械加载或覆盖现役模型。

若人员确认连接并明确开始采集：由人员在安全范围内执行无载、缓慢加载、保持、卸载、重复按压；你记录全部原始双流及时间戳，并记录真实动作起止、无载确认、参考/tare/断流事件。没有执行的动作写未做。坐标/标定缺口保留。

尽可能导出实际推理入口张量、位移/编码、ONNX 原始输出和显示值。若只能取连续子片段，明确范围；不能拿 Python 重算冒充 SDK dump。

按合同封存 session，运行 tools/session_integrity.py seal/verify。生成 quality_report 和交接清单。数据保留本地；只把已批准的小文件提交私有仓库，大包按双方批准的私有附件路线传输并记录 SHA256。

开 PR 写：实际采集还是历史/模拟、硬件与帧/样本数、时长、命令/日志、模型配置身份、数据访问位置和哈希、已完成/缺口、下一步。不要声称完整性 PASS 就是物理同步/准确率 PASS。
